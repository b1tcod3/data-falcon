# Fundamentos de Programación (Python)

Ejemplos introductorios para practicar la sintaxis básica de Python.

## Contenido

- `condicionales.py`: condicional simple (`if` / `else`).
- `condicionales-multiples.py`: sistema de calificaciones con `elif`.
- `condicionales-en-linea.py`: operador ternario (`valor_si_true if condición else valor_si_false`).
- `bucles.py`: bucle `for` sobre secuencias.
- `casting.py`: conversión segura de tipos con manejo de errores.
- `calculadora-casting.py`: calculadora que convierte la entrada de texto a números.
- `calculador.py`: calculadora más completa con menú de operaciones.

## Cómo ejecutar

```bash
python3 programacion-general/tutorials/fundamentos/condicionales.py
```
