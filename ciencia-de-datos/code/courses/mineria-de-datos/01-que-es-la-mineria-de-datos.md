# ¿Qué es la Minería de Datos?

La **Minería de Datos** (o *Knowledge Discovery and Data Mining*, KDD) se define como un **oficio analítico y artesanal** centrado en la **búsqueda automatizada** de conocimiento, patrones y regularidades ocultas dentro de grandes volúmenes de datos.

Más allá de ser una simple aplicación de algoritmos, se caracteriza por los siguientes pilares fundamentales:

## Propósito Predictivo y de Generalización

No busca únicamente explicar el pasado histórico, sino extraer modelos matemáticos capaces de generalizarse a datos nuevos y no vistos para predecir comportamientos futuros. A diferencia de un reporte descriptivo que solo resume lo que ya ocurrió, la minería de datos construye patrones que anticipan lo que está por venir.

## Enfoque de Negocio

Su objetivo final es generar conocimiento útil que soporte directamente la toma de decisiones empresariales y comerciales. No se hace minería de datos por el simple hecho de aplicar algoritmos interesantes; se hace para resolver problemas concretos que generan valor a la organización.

## Estructurada por un Proceso

No depende de la intuición aislada, sino que se rige por un marco de trabajo sistemático, iterativo y repetible (como el ciclo **CRISP-DM**), que abarca desde la comprensión del problema comercial hasta el despliegue operativo. Este proceso se cubre en detalle en el [módulo de CRISP-DM](./CRISP-DM/) de este curso.

## Relación con la Ciencia de Datos

Para entender mejor qué es la minería de datos, conviene contrastarla con la ciencia de datos, su disciplina marco. Mientras que la [Ciencia de Datos](./03-ciencia-de-datos-vs-mineria.md) es el conjunto de principios teóricos que guían la extracción de conocimiento, la Minería de Datos es la ejecución práctica de esos principios usando algoritmos y tecnologías concretas.
