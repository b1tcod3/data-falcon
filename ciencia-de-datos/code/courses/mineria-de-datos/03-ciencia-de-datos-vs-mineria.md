# Ciencia de Datos vs. Minería de Datos

Aunque en la industria suelen usarse como sinónimos, existe una distinción conceptual importante entre Ciencia de Datos y Minería de Datos. Comprender esta diferencia ayuda a ubicar cada término en su contexto correcto y a utilizarlos con precisión.

## Ciencia de Datos (Data Science)

Es el **marco conceptual y teórico** que define los principios fundamentales para extraer conocimiento de la información. Abarca:

- La formulación de preguntas de investigación y negocio.
- El diseño de metodologías para recolectar, limpiar y transformar datos.
- Los fundamentos estadísticos y matemáticos que garantizan la validez de los resultados.
- La interpretación de resultados y su traducción a decisiones.
- Las consideraciones éticas sobre privacidad, sesgo y transparencia.

> La Ciencia de Datos responde al **qué** y al **por qué**: qué principios rigen el proceso y por qué ciertos métodos funcionan.

## Minería de Datos (Data Mining)

Es la **ejecución práctica y técnica**: la extracción real de patrones y conocimiento a partir de datos utilizando algoritmos y herramientas computacionales. Incluye:

- Aplicación de algoritmos de clasificación, regresión, clustering y asociación.
- Técnicas de reconocimiento de patrones en grandes volúmenes de datos.
- Implementación de modelos predictivos y descriptivos.
- Uso de bases de datos, lenguajes de programación y plataformas de procesamiento.

> La Minería de Datos responde al **cómo**: cómo se aplican los algoritmos para descubrir patrones.

## Tabla comparativa

| Aspecto | Ciencia de Datos | Minería de Datos |
|---------|-----------------|------------------|
| Enfoque | Teórico y metodológico | Práctico y operativo |
| Alcance | Todo el ciclo de vida del dato | Extracción de patrones |
| Pregunta | ¿Qué problema resolver y por qué? | ¿Qué algoritmo usar y cómo? |
| Entrega | Insights, recomendaciones, estrategias | Modelos, reglas, patrones |
| Herramientas | Estadística, diseño experimental | Algoritmos, bases de datos, software |

## ¿Por qué se usan como sinónimos?

En la práctica profesional, un proyecto de Ciencia de Datos implica inevitablemente Minería de Datos, y viceversa. No se puede hacer uno sin el otro. Las empresas contratan "científicos de datos" para que hagan "minería de datos", y los títulos de los puestos reflejan más la demanda del mercado que una distinción académica.

## Ejemplo concreto

Imagina que un hospital quiere predecir qué pacientes tienen riesgo de readmisión:

- **Ciencia de Datos:** Define el problema, identifica qué variables clínicas son relevantes, establece métricas de éxito (precisión, recall), evalúa si el modelo es éticamente aceptable.
- **Minería de Datos:** Entrena un árbol de decisión o una red neuronal sobre los datos históricos de pacientes, ajusta hiperparámetros, evalúa el rendimiento del modelo.
